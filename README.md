# 📩 SMS Spam Classifier

A simple **Machine Learning project** to classify SMS messages as **Spam** or **Ham (Not Spam)** using **TF-IDF + Naive Bayes**.  
Built with **Python, scikit-learn, and Streamlit**.

---

## 🚀 Features
- Text preprocessing (tokenization, stopword removal, stemming).
- Multiple ML models tested (Naive Bayes, Logistic Regression, SVM, Random Forest, etc.).
- Final deployment uses a **Pipeline (TF-IDF + MultinomialNB)**.
- Interactive **Streamlit Web App**.
- Shows **confidence scores** for predictions.
